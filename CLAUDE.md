# Player Guide — instructions for Claude

This repo is the **public player website** (MkDocs Material → GitHub Pages). Read **`MAINTAINING.md`** first for how to edit, preview, and publish.

**Before publishing anything about the campaign:** this is read by the players. Run the spoiler check from the GM's private notes (see MAINTAINING.md) — and publish **only** what the players' characters have actually seen or learned. If unsure, leave it out.

Rules: use `[Text](Page.md)` links (no `[[wiki links]]`); add new pages to `nav:` in `mkdocs.yml`; run `mkdocs build --strict` before pushing; **only commit/push when the GM asks.**

**Home page:** it is onboarding until the first recap exists; after that, follow "The Home page evolves" in `MAINTAINING.md` (latest recap / where we left off / what we're wondering).
